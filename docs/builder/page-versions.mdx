# Page Versions

Versioning layouts.

Every time you save in the builder, a new `PageVersion` is created. This stores the `nodeTree` JSON, allowing you to rollback or draft changes without affecting the published site.

### Lifecycle

1. **Draft**: Editing creates a new draft `PageVersion`.
2. **Preview**: Renders the current draft.
3. **Published**: Marks the `PageVersion` as active, overriding the live site.
