# Introduction

Welcome to Business OS. Learn how to navigate the platform, manage workspaces, and build sites visually.

Business OS is a multi-tenant platform for building and publishing websites. At its core, the platform is divided into Workspaces. Each workspace can contain multiple websites, media assets, and team members.

## Core Concepts

- **Workspace**: The top-level boundary of isolation.
- **Website**: A collection of pages, CMS data, and themes.
- **Builder**: The visual editor representing your site layout as a `nodeTree`.
