# Preview

Previewing changes.

Preview mode renders the draft `PageVersion` exactly as it will appear when published, bypassing the CDN cache. 

<Callout type="info" title="Shareable Previews">
You can share the preview URL with your team to gather feedback before publishing.
</Callout>
