# Template Business OS

Welcome to **Template Business OS**, a robust and scalable B2B SaaS platform template built with modern web technologies. This project serves as a comprehensive foundation for building business operating systems, offering features like workspace management, website deployment, media libraries, billing, and support ticketing.

## 🚀 Features

- **Workspace Management**: Create and manage multiple workspaces. Assign roles (Owner, Admin, Member) and manage team access.
- **Website Management**: Deploy and manage websites directly from the dashboard. Support for custom domains and templates.
- **Media Library**: A centralized asset management system to upload, organize (with folders), and favorite media files.
- **Billing & Subscriptions**: Integrated billing dashboard to manage subscription plans, usage, and invoices.
- **Support Center**: Built-in ticketing system for user support and issue tracking.
- **Authentication & Security**: Secure user authentication and authorization.
- **Modern UI/UX**: A beautiful, responsive, and animated user interface built with Tailwind CSS and Framer Motion, following a unified "Blueprint" design language.

## 🛠 Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Database/ORM**: [Prisma](https://www.prisma.io/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 📦 Getting Started

First, install the dependencies:

```bash
bun install
# or
npm install
# or
yarn install
```

Set up your environment variables by creating a `.env` file based on the provided example (if any). Make sure to configure your database connection string and authentication secrets.

Run the development server:

```bash
bun dev
# or
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

# Template Business OS (Bahasa Indonesia)

Selamat datang di **Template Business OS**, sebuah template platform B2B SaaS yang tangguh dan skalabel, dibangun dengan teknologi web modern. Proyek ini berfungsi sebagai pondasi komprehensif untuk membangun sistem operasi bisnis, menawarkan fitur-fitur seperti manajemen ruang kerja (workspace), deployment website, pustaka media, penagihan (billing), dan sistem tiket dukungan (support).

## 🚀 Fitur Utama

- **Manajemen Workspace**: Buat dan kelola banyak workspace. Tetapkan peran (Owner, Admin, Member) dan kelola akses tim.
- **Manajemen Website**: Deploy dan kelola website langsung dari dashboard. Mendukung kustom domain dan template.
- **Pustaka Media (Media Library)**: Sistem manajemen aset terpusat untuk mengunggah, mengatur (dengan folder), dan memfavoritkan file media.
- **Billing & Langganan**: Dashboard penagihan terintegrasi untuk mengelola paket langganan, penggunaan, dan tagihan/invoice.
- **Pusat Bantuan (Support Center)**: Sistem tiket bawaan untuk dukungan pengguna dan pelacakan masalah.
- **Autentikasi & Keamanan**: Autentikasi dan otorisasi pengguna yang aman.
- **UI/UX Modern**: Antarmuka pengguna yang indah, responsif, dan dinamis, dibangun dengan Tailwind CSS dan Framer Motion, mengikuti bahasa desain "Blueprint" yang seragam dan elegan.

## 🛠 Teknologi yang Digunakan

## 📦 Cara Memulai

Pertama, instal semua dependensi:

npm install
