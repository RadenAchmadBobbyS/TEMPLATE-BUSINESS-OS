# Plans

Subscription Tiers.

The `SubscriptionTier` enum defines the available plans:
- **FREE**: Basic access.
- **STARTER**: Increased limits.
- **PRO**: Custom domains and advanced analytics.

These tiers map directly to `PLAN_LIMITS` enforced throughout the application.
